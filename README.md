1. Pengertian Bootstrap  
Bootstrap adalah sebuah framework front‑end berbasis HTML, CSS, dan JavaScript yang digunakan untuk mempermudah pembuatan tampilan website.
Dengan Bootstrap, pengembang dapat membuat desain yang konsisten, responsif, dan menarik tanpa harus menulis kode CSS dari awal.
Framework ini menyediakan berbagai komponen siap pakai seperti tombol, form, navbar, dan grid sehingga proses pengembangan menjadi lebih cepat dan efisien.

3. Memasang Bootstrap  
Ada beberapa cara untuk menggunakan Bootstrap dalam sebuah project.
Pertama, dengan memanfaatkan CDN (Content Delivery Network) yaitu menambahkan link CSS dan JavaScript Bootstrap langsung dari internet.
Kedua, dengan mengunduh file Bootstrap lalu menyimpannya di folder project untuk digunakan secara lokal.
Ketiga, dengan menginstal Bootstrap melalui package manager seperti npm atau yarn sehingga integrasi dengan project modern lebih mudah dilakukan.

5. Grid dan Breakpoint  
Bootstrap menyediakan sistem grid yang berbasis pada kolom untuk mengatur tata letak halaman.
Grid ini memungkinkan pembagian halaman menjadi beberapa bagian yang rapi dan fleksibel.
Breakpoint adalah ukuran layar tertentu yang digunakan Bootstrap untuk menyesuaikan tampilan agar responsif.
Dengan breakpoint, elemen website dapat berubah posisi atau ukuran sesuai perangkat, misalnya
pada layar kecil (mobile) atau layar besar (desktop).

7. Class Bootstrap  
Bootstrap menyediakan banyak class siap pakai. Contohnya:
btn btn-primary untuk membuat tombol berwarna biru.
text-center untuk meratakan teks ke tengah.
bg-danger untuk memberi latar belakang merah.
container untuk membuat wadah utama dengan padding otomatis.
row dan col untuk membangun layout grid.
Class‑class ini membantu mempercepat styling tanpa harus menulis CSS manual.

5. Gambar Responsif  
Agar gambar pada website responsif, Bootstrap menyediakan class img-fluid.
Dengan menambahkan class ini pada tag <img>, gambar akan otomatis menyesuaikan ukuran layar perangkat tanpa keluar dari batas kontainer.
Hal ini memastikan tampilan gambar tetap proporsional baik di layar kecil maupun besar.
